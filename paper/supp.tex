\section{Reproduction}
From a fresh clone of the repository (branch \texttt{main}; see \texttt{CLAUDE.md} and \texttt{documentation/full\_pipeline.md}):
\begin{verbatim}
pip install -r requirements.txt     # requirements.lock pins versions
python -m src.pipeline --list       # what would run / skip
python -m src.pipeline              # classifier -> reward -> generator
                                    #   -> screen -> report
python -m src.train_hybrid --run-all --norm batch
                                    # reported classifier
python -m src.reward                # reward gate; if it fails, stop
python -m src.brics_generator --pretrain   # MLE warm start (required)
python -m src.train_gan --generator brics --steps 250 --threads 6 \
    --seed 0 --reward-seed 0 --kl-coef 1.0 --drop C --min-c 0.615 \
    --warm-start results/generator/bbbp_brics_pretrained.pt \
    --out-dir results/brics_cgate/pseed0
python -m src.postfilter results/brics_cgate/* --from-step 150 \
    --rank-by mpo_gated --out results/candidates_mpo/brics_cgate
python paper/make_figs.py
python paper/make_supp.py
python paper/scaffold_overlap.py
\end{verbatim}
\texttt{--kl-coef 1.0} is mandatory for BRICS (the default $0.3$ was validated for SELFIES only); runs are comparable only at a fixed thread count.

\section{Corrections made to earlier claims}
The repository records the following hypotheses that measurement overturned; the first group is listed in the repository's \path{limitations.md}, the last item concerns this manuscript.
\begin{enumerate}[leftmargin=2.4em]
\item ``195/199 distinct samples, so no mode collapse'': wrong metric; string uniqueness is blind for about 100 steps.
\item ``The collapse is property-space, with only mild scaffold narrowing'': true at step 40, over-generalized; at 200 steps scaffold collapse is larger.
\item ``The reward uses the wrong classifier'': overclaimed; no measurable out-of-distribution difference.
\item ``Off-distribution the ensemble will disagree'': backwards; it agrees more.
\item ``Architecture differences are hopeless at 3 seeds'': used marginal sds; the design is paired.
\item ``The reward has gone blind'': overstated; the information is there on a scale that could not show it.
\item Descriptor distance, applicability domain and Tox21 were each expected to catch the solvents; none does.
\item ``The alert penalty makes the generator cleaner than approved drugs'': true only on the instrument it was trained against (BRENK: $0.406$ against drugs' $0.350$).
\item BRICS ``loses diversity because of its compact action space'': retracted; the KL coefficient did not transfer ($10.7\times$ the KL).
\item The three-seed GAT-over-GIN effect did not replicate at ten seeds ($+0.0109$, CI $[-0.0057,+0.0275]$); the three-seed scaffold mean ($0.864$) was one unlucky draw ($0.854$ at ten).
\item A trioxide said to pass the screen did not (arm A's pool only); a ring-strain pattern that flagged 138 survivors was a labelling error and was removed.
\item \emph{This manuscript:} Table~2 standard deviations for hybrid-BatchNorm ($0.032$, $0.047$) and the 8-descriptor LightGBM value on B3DB ($0.852\pm0.040$) were corrected against the result CSVs (the repository README table carries the earlier values); the claim that no calibration analysis exists was replaced by the measurement above; ``36.8\% share a training scaffold'' referred to an older two-run survivor set and was recomputed ($34.8\%$ arm A, $23.5\%$ gate arm, \texttt{scaffold\_overlap.py}).
\end{enumerate}
