\begin{frame}{Why this problem}
\begin{itemize}\itemsep4pt
  \item Whether a molecule crosses the blood--brain barrier (BBB) decides if it can act on the CNS.
  \item Labelled data are small: BBBP $\approx$ 2\,000 compounds, B3DB $\approx$ 8\,000.
  \item GNNs rank well on them, so it is tempting to reuse the trained network as the \textbf{reward} of a generator.
  \item But a generator queries the classifier on molecules \emph{chosen to maximize its output}, so any weakness is actively sought out.
\end{itemize}
\vspace{4pt}
\textbf{Question:} what happens when we do exactly that, and which interventions actually help?
\end{frame}

\begin{frame}{System and protocol}
\centering
SMILES $\rightarrow$ RDKit graph $\rightarrow$ GNN $\rightarrow$ $P(\text{BBB permeable})$ \quad $\Longrightarrow$ \quad frozen reward for a GRPO generator
\vspace{6pt}
\begin{itemize}\itemsep3pt
  \item \textbf{Leak-corrected scaffold split:} the standard Murcko grouping silently excluded acyclic molecules from every test fold; we fix this.
  \item \textbf{Ten seeds}; each seed is a different scaffold split, so $\pm$ includes split variance.
  \item \textbf{External holdouts} (Adenot, Wang) filtered to be scaffold-disjoint from both training sets.
  \item Frozen classifier means \texttt{eval()}: BatchNorm in train mode would make a molecule's reward depend on its group.
\end{itemize}
\end{frame}

\begin{frame}{Generator and the two-part advantage}
\begin{itemize}\itemsep3pt
  \item GRPO replaces the value function by group statistics; here rewards are \emph{zero-inflated} (invalid $\rightarrow$ flat penalty).
  \item Pooling zeros and valid molecules lets a few invalids set the scale for ranking the valid ones.
  \item \textbf{Hurdle advantage:} standardize within the valid subgroup; invalids get a fixed floor.
\end{itemize}

  \item Every metric the loop originally logged looks healthy

\begin{frame}{Why: what a group-standardized update cannot see}
\begin{columns}[c]
\column{0.50\textwidth}
\begin{itemize}\itemsep4pt
  \item The standardized advantage is \textbf{blind to the absolute reward level}.
  \item Reweighting reward terms \emph{inside} it does not restrain the collapse.
  \item Only quantities acting \emph{outside} it do: a size gate, a fixed invalidity floor, a KL penalty.
\end{itemize}

\begin{frame}{Permeability as a gate, not a direction}
\begin{columns}[c]
\column{0.42\textwidth}
\begin{itemize}\itemsep4pt
  \item BBBP: \textbf{+73\%} distinct output
  \item Corpus reproduction: $88.9\% \rightarrow 68.4\%$
  \item B3DB replication: gain shrinks to \textbf{+18\%}
  \item Mechanism: the benefit scales with how badly the policy had memorized its corpus

\begin{frame}{Shortlist and limitations}
\begin{columns}[c]
\column{0.50\textwidth}
\begin{itemize}\itemsep4pt
  \item The BBBP label measures \textbf{transport, not drug suitability}: a permeability objective rewards small lipophilic solvents.
  \item This limitation is unresolved.
  \item All outputs are \textbf{hypotheses, not synthesis candidates}.
\end{itemize}

\begin{frame}{Take-aways and code}
\begin{enumerate}\itemsep4pt
  \item A corrected split and ten seeds show most architecture differences are noise; descriptors and BatchNorm are what help.
  \item Reusing a classifier as a reward collapses diversity while standard metrics look fine.
  \item A group-standardized update is blind to absolute reward level: constrain from outside it.
  \item A permeability \emph{gate} helps most when the policy memorizes its corpus.
\end{enumerate}
